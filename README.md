# Tray Battery

Tray Battery shows the battery level of a connected Bluetooth mouse and headphones in two native Windows tray icons. Hover over an icon to see its device name and charge; left-click does nothing, and right-click opens a small menu for refresh, startup settings, or exit. Build on Windows with MinGW-w64 `g++` and Rust stable installed on `PATH` by running `build.bat`; set `GXX` or `CARGO` to an executable path if needed. The executables are written to `dist/`. Download release builds from [GitHub Releases](https://github.com/fawk-ux/batt-tray/releases/latest).
